# Pizza App — Vue 3 + Express

Samostalni Zadatak za vježbu 3

Ovaj projekt sastoji se od **frontend** i **backend** dijela.  
Frontend je izrađen u **Vue 3 (Vite)**, a backend koristi **Express.js**.

## Struktura projekta

/app/
├── README.md
├── pizza-vue/
└── pizza-express/

## Pokretanje Frontenda

cd pizza-vue
npm install
npm run dev

Frontend radi na: http://localhost:5173

## Pokretanje Backenda

cd pizza-express
npm install
node index.js

Backend radi na: http://localhost:3000

## Pokretanje aplikacije

Otvorite: http://localhost:5173

## API Rute

GET /pizze  
GET /pizze/:naziv  
POST /narudzbe
